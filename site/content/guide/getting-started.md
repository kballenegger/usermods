# Getting started with usermods

usermods needs Chrome 135 or later.

1. [Add usermods to Chrome](/install?from=/guide/getting-started) from the Chrome Web Store.
2. Open `chrome://extensions`, click **Details** on usermods, and turn on **Allow User Scripts**. Chrome requires this toggle for any extension that runs user scripts, including Tampermonkey.
3. Click the usermods icon to open the side panel on the tab you want to change. Go to **Settings**, click a preset under **Add provider**, and paste a key or a local server URL. Back in **Chat**, describe the change you want.
