# usermods — iOS / macOS icon options

Five generated app-icon explorations in the canonical BBS Underground identity. Open `index.html` to compare rounded-mask previews, full-square artwork, and small-size readability. The existing canonical product icon is unchanged.

## Options

- 01 **BBS Classic** — `01-bbs-classic.png` (1254 × 1254). The closest to the canonical pixel mark.
- 02 **Pixel Relief** — `02-pixel-relief.png` (1254 × 1254). Subtle layered depth, with the same stepped silhouette.
- 03 **Night Terminal** — `03-night-terminal.png` (1254 × 1254). A dark field with bright ANSI corner accents.
- 04 **Browser Badge** — `04-browser-badge.png` (1254 × 1254). The u inside a minimal browser window.
- 05 **Modular U** — `05-modular-u.png` (1254 × 1254). One lifted pixel suggests a customizable app.

## Files and handoff

The PNGs are original generated square artwork. Preview masks are illustrative and do not alter the downloaded images. These are visual options, not completed Xcode asset catalogs or layered icon packages. Once an option is chosen, prepare the platform-specific assets from that design.

`prompts.json` contains all five exact prompts and reference paths. `manifest.json` records the generated file sources and dimensions. Generation used the built-in image generator.
