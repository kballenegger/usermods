# usermods DMG background options

Ten image-generated backgrounds using the project’s canonical BBS Underground style. Open `index.html` to compare the artwork and toggle an illustrative app/folder overlay. Downloaded background PNGs contain no app or folder icons.

## Layout for handoff

- Landscape 3:2 artwork; exact native dimensions are listed below.
- Suggested Finder content area: 768 × 512 logical points.
- App icon center: x=28%, y=55% (about 215, 282 points in that content area).
- Applications alias center: x=72%, y=55% (about 553, 282 points).
- Suggested icon size: 96 points. Leave room below for Finder filenames.
- Arrow and installation instruction are already in the artwork.
- This pack contains background options; no DMG build settings or existing product assets were changed.

## Generation

Built-in image generator. Exact prompts and the canonical reference path are in `prompts.json`; native output paths, dimensions and byte sizes are in `manifest.json`. Original generated files are copied without pixel edits. `preview-app.png` and `preview-applications.svg` are gallery-only placement references.
